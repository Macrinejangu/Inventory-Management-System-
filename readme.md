# Inventory Management System

A Flask REST API and command-line interface for managing retail inventory.
Product details are retrieved from OpenFoodFacts by barcode or name.
Selected products are imported with a store-defined price and stock quantity.

## Requirements

- Python 3.12
- Git
- Internet access for OpenFoodFacts lookup and import

## Installation

```bash
git clone https://github.com/Macrinejangu/Inventory-Management-System-.git
cd Inventory-Management-System-
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Start the API

```bash
python -m flask --app app run --port 5555
```

Keep this terminal running. Open a second terminal for CLI commands:

```bash
cd ~/Inventory-Management-System-
source .venv/bin/activate
```

## CLI Examples

List inventory:

```bash
python cli.py list
```

Create an item:

```bash
python cli.py add --name "Almond Milk" --price 250 --stock 10
```

View, update, and delete an item:

```bash
python cli.py show 1
python cli.py update 1 --price 275 --stock 15
python cli.py delete 1
```

Search external products:

```bash
python cli.py search "almond milk"
```

Preview a product using a barcode returned by the search:

```bash
python cli.py barcode BARCODE
```

Import the selected product:

```bash
python cli.py import BARCODE --price 250 --stock 10
```

Replace BARCODE with the selected product's barcode.
Use --name to supply a product name if the external record lacks one.

For another server address:

```bash
python cli.py --base-url http://127.0.0.1:5555 list
```

The INVENTORY_API_URL environment variable also sets the default address.

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | / | Welcome message |
| GET | /inventory | List inventory |
| GET | /inventory/<id> | Retrieve an item |
| POST | /inventory | Create an item |
| PATCH | /inventory/<id> | Update selected fields |
| DELETE | /inventory/<id> | Delete an item |
| GET | /products/barcode/<barcode> | Look up an external product |
| GET | /products/search?name=milk | Search external products |
| POST | /inventory/import | Fetch a barcode and add the product |

## Data and Validation

Each inventory item contains:

- id
- barcode
- product_name
- brands
- ingredients_text
- price
- stock

Creation requires a non-empty product_name, price, and stock.
Stock must be a non-negative integer.
Price must be finite, non-negative, and have at most two decimal places.
The maximum supported price is 999999999.99.
Price values use a consistent store currency chosen by the operator.
Unknown input fields are rejected.

PATCH changes only supplied fields. Invalid updates preserve existing data.
IDs are generated by the server and are not reused during its lifetime.

Import requires barcode, price, and stock. Product details come from
OpenFoodFacts. Search and preview do not modify inventory.

## Responses

- 200: Successful retrieval or update
- 201: Item created or imported
- 204: Item deleted, with no response body
- 400: Invalid input
- 404: Item or external product not found
- 415: Missing or unsupported JSON content type
- 502: External service request failed

Send POST and PATCH bodies using Content-Type: application/json.

## Tests

```bash
python -m pytest tests -q
```

The suite covers inventory CRUD, validation, application isolation,
CLI commands, external lookup, import, and simulated service failures.
External HTTP calls are mocked during automated tests.

## Limitations

Inventory uses an in-memory list. Restarting the server clears stored items.
Run one server process for consistent inventory state.

Authentication is outside this lab's scope. This application is a local
learning prototype.
